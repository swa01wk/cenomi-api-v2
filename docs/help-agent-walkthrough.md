# Help Agent — AI-Assisted Platform Help Walkthrough

A quick walkthrough of the Help Agent on Tenant Central — contextual answers, page summaries, and guided how-tos, all from the AI Assistance rail. *(Reference video attached.)*

## 1 · Open the Help Agent

1. Log in to [Tenant Central](https://tenantcentral.cenomi.com).
2. Open the **AI Assistance rail** — the Help Agent is available throughout the platform.

## 2 · Ask About a Mall

1. From the main menu, click **Malls** and select **Yasmeen Mall**.
2. Ask the agent questions about the mall in natural language, for example:
   - *"Who is the mall manager?"*
   - *"At what time can I visit the mall?"*
   - *"Where is the loading dock?"*
3. The agent answers with mall-specific details, grounded in the platform's help content.

## 3 · Know About the Current Page

1. At the top of the co-pilot, click **Know about current page**.
2. The agent generates a **summary of the page you're on**, built from the platform's help content — instant orientation without leaving the screen.

## 4 · Suggested Questions

1. The rail offers **pre-created questions** — click one to ask instantly, for example: *"How do I submit a service request?"*
2. The agent replies with clear **step-by-step guidance** for that task.

---

*The Help Agent turns platform documentation into a conversation — mall information, page context, and how-to steps on demand, with no searching through manuals.*
