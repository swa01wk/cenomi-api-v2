# Handover Service Request — AI-Assisted Creation Walkthrough

A quick walkthrough of creating a Handover Service Request on Tenant Central using the AI Assistant. *(Reference video attached.)*

## 1 · Navigate

1. Log in to [Tenant Central](https://tenantcentral.cenomi.com).
2. From the main menu, go to **Operations → Service Request**.
3. On the Service Request page, click **+ Service Request**.
4. Select **Category:** Fit Out and Handover · **Sub-category:** Handover.

## 2 · Start with AI

Two entry points — both land in the same conversation:

| Entry point | What happens |
|---|---|
| **Create with AI** | The platform passes the request to the agent automatically — the conversation starts pre-filled. |
| **AI Assistance rail** | Open the rail and type *"I want to create a handover service request."* |

## 3 · Converse

The agent guides the request step by step:

1. **Lease** — provide the lease code when prompted; the agent resolves the lease and confirms the tenant.
2. **Handover type** — choose **Initiate Handover**.
3. **Request details** — answer as asked: title, description, inspection dates, inspection done by, notes, comments, and an optional document upload.

## 4 · Review & Submit

1. The agent presents a **preview** of the complete request.
2. Click **Submit** — the Service Request is created instantly.
3. Click **View Service Request** to open the SR created with the agent's help.

---

*End-to-end, the agent replaces the multi-field form with a short guided conversation — lease lookup, validation, and submission are handled automatically.*
